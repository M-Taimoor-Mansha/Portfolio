# Muhammad Taimoor Mansha — Portfolio (HTML / CSS / JavaScript)

Pure HTML5 + CSS3 + vanilla JavaScript (ES6+). No build step, no framework.

## Files
- `index.html` — markup for all sections (Hero, About, Skills, Education & Certificates, Projects, Contact, Footer)
- `style.css` — dark neon / glassmorphism design system, fully responsive
- `script.js` — Three.js hero scene, GSAP ScrollTrigger reveals, typing text, 3D tilt cards, custom cursor, loader, mobile nav, contact form
- `assets/taimoor-profile.jpeg` — your navbar photo (add this file; a "TM" monogram shows if it's missing)

## CDNs used
Three.js (r128), GSAP + ScrollTrigger, FontAwesome 6, Google Fonts (Orbitron + Rajdhani).

## Run it
Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy
Upload the folder to GitHub Pages, Netlify, or Vercel as a static site.
